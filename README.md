## 🇧🇷 Português

Modelo de landing page temática de Fórmula 1, inspirada na estética visual das pistas (como o zebrado de Interlagos) e no design oficial da categoria. O projeto foi desenvolvido com foco em layout responsivo, hierarquia visual e experiência do usuário.

### ✨ Funcionalidades
* **Hero Section:** Banner com corte diagonal (`clip-path`), estatísticas do circuito e chamadas para ação (CTAs).
* **Grid de Pilotos:** Cards estilizados com as cores e numerações das equipes (Ferrari, McLaren, Mercedes, Audi).
* **Tabela de Classificação:** Exibição de pontuação com destaque para o líder e barra de filtros por piloto/equipe.
* **Venda de Ingressos:** Seção com tabela de preços por setor, alertas de disponibilidade e formulário de reserva.
* **Design Responsivo:** Layout adaptado para desktop, tablets e smartphones.

### 🛠️ Tecnologias Utilizadas
* **HTML5** (Estrutura semântica)
* **CSS3** (CSS Grid, Flexbox, variáveis de cores, `clip-path` e Media Queries)
* **Google Fonts** (`Titillium Web`)

## 🇺🇸 English

A Formula 1 themed landing page template inspired by racetrack aesthetics (such as Interlagos curbs) and official motorsport visual identity. Built with a focus on responsive layout, visual hierarchy, and user experience.

### ✨ Features
* **Hero Section:** Diagonal clipped banner (`clip-path`), circuit stats overlay, and clear call-to-action buttons.
* **Drivers Grid:** Custom cards styled with team colors and driver numbers (Ferrari, McLaren, Mercedes, Audi).
* **Standings Table:** Championship points table highlighting the current leader, paired with search and team filters.
* **Tickets Section:** Sector pricing breakdown, availability alerts, and a ticket reservation form.
* **Responsive Design:** Fully adapted layout for desktop, tablet, and mobile devices.

### 🛠️ Tech Stack
* **HTML5** (Semantic markup)
* **CSS3** (CSS Grid, Flexbox, `clip-path`, and Media Queries)
* **Google Fonts** (`Titillium Web`)
